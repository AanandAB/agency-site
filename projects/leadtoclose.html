Core System Architecture

📊

7-Stage Deal Pipeline

Structured sales funnel from New Lead → Contacted → Qualified → Proposal Sent → Negotiation → Won → Lost. Features dynamic lead health scoring (hot, warm, cold) and automated conversion into billable contracts in one tap.

💾

Local-First Hive Storage

No mandatory monthly SaaS subscriptions or remote cloud dependency. Client records, task milestones, and billing documents persist in encrypted local binary Hive boxes with instant millisecond search.

⏱️

Integrated Time & Stopwatch Tracker

Precision project time-logging tool that links billable hours directly to client invoices. Tracks budget-vs-actual hours with weekly efficiency breakdowns and multi-currency billing presets.

📑

Proposals, SOW & Contracts

Built-in templates for Statements of Work (SOW), Master Service Agreements (MSA), and Non-Disclosure Agreements (NDA). Automatically interpolates client metadata into legally formatted documents.

🧾

Automated Invoicing & Tax Engine

Draft, send, and audit invoices with automatic overdue status alerts, line-item discounts, GST computation, and payment status dashboards.

🎨

Dual Theme & Desktop Inno Setup

Tailored light/dark high-contrast design with keyboard accelerators. Shipped with a production Inno Setup Windows installer script (`setup.iss`) for single-click desktop deployment.

State Architecture Sample

@riverpod
class PipelineNotifier extends _$PipelineNotifier {
  @override
  PipelineSummary build() {
    final leadsBox = Hive.box<Lead>('leads_cache');
    return _calculateMetrics(leadsBox.values.toList());
  }

  Future<void> advanceStage(String leadId, DealStage nextStage) async {
    final lead = state.findLead(leadId);
    lead.stage = nextStage;
    await lead.save(); // Instantly committed to Hive binary box
    state = _calculateMetrics(state.allLeads);
  }
}
